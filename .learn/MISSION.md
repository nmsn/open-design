# Mission: 从前端开发者到全栈 AI 应用工程师

## Why

你是一名前端程序员，希望扩展技术栈到全栈开发和 AI 应用领域。Open Design 是一个你喜爱的开源项目，它恰好涵盖了你需要学习的所有核心技术：Node.js 后端（Express + SQLite）、AI 代理编排（多 Agent CLI 集成）、MCP 协议、SSE 流式通信、Electron 桌面端。通过深入理解这个项目的架构和实现，你将获得从"只会写前端"到"能独立交付 AI 应用"的能力跃迁。

## Success looks like

- 能独立阅读和理解 Open Design 的 daemon 源码（Express 路由、SQLite 数据库、Agent 流处理）
- 能为项目提交有意义的 PR（bug fix 或小功能），并通过 code review
- 能用 Node.js + Express + SQLite 从零搭建一个带 AI 对话功能的全栈应用
- 理解 MCP 协议、SSE 流式通信、Agent 编排等 AI 应用核心概念
- 能向他人解释 Open Design 的架构设计决策及其 trade-off

## Constraints

- 学习材料以 Open Design 项目为主线，辅以外部资源
- 每个课程控制在 15-30 分钟内完成
- 优先学习对提 PR 有直接帮助的知识
- 中文教学

## Out of scope

- 深度学习/机器学习模型训练（本课程关注 AI 应用层，不是模型层）
- DevOps/部署运维（Docker、K8s 等）
- 移动端开发
- 大规模分布式系统设计
