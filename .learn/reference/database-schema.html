📋 表清单与用途

🟣 核心业务 — 聊天主链路

📁
projects
项目注册表。每个项目是一个设计任务的容器，记录使用的技能（skill_id）和设计系统（design_system_id）。
例：用户创建一个"产品发布会 PPT"项目
💬
conversations
聊天会话。一个项目可以有多轮对话，每轮对话是一个 conversation。session_mode 区分设计模式和普通聊天。
例：用户对同一个项目发起"第一版"和"修改版"两轮对话
✉️
messages
聊天消息。每条消息记录角色（user/assistant）、内容、SSE 事件流、生成的文件、反馈等。是数据量最大的表。
例：用户说"帮我做一个蓝色主题的 PPT"，AI 回复包含 HTML 代码
🤖
agent_sessions
代理会话追踪。记录哪个代理（Claude/Codex 等）在处理哪个对话，以及会话 ID 和提示词哈希（用于缓存）。
例：Claude Code 处理了对话 c1，会话 ID 为 sess_abc123

🟢 制品与 UI — 界面状态

📝
preview_comments
制品评审评论。用户在预览的 HTML 制品上选中元素，添加批注。记录选中的 CSS 选择器、位置、状态（待处理/已解决）。
例：用户在 PPT 第 3 页的标题上标注"字体太大"
🗂️
tabs
工作区标签页。记录用户打开了哪些文件标签，以及它们的排列顺序和当前激活的是哪个。
例：用户打开了 index.html、style.css、readme.md 三个标签
⚙️
tabs_state
标签页状态。存储每个项目的标签页 UI 状态（JSON 格式），如滚动位置、分屏比例等。
例：用户把编辑器分成了左右两栏，左侧 60%，右侧 40%

🟠 自动化 — 定时任务

⏰
routines
自动化例程定义。用户创建的定时任务，如"每天早上 9 点生成一份日报"。记录调度规则、使用的技能和代理。
例：每周一 10:00 用 Claude 生成团队周报
▶️
routine_runs
例程执行记录。每次定时任务触发后生成一条记录，记录状态（成功/失败）、关联的项目和对话、错误信息。
例：周报任务在 6 月 23 日执行成功，生成了对话 c5
🔒
routine_schedule_claims
调度锁。防止同一个定时任务在同一时间窗口被重复执行。通过 routine_id + 时间槽实现分布式锁。
例：10:00 这个时间槽已被实例 A 领取，实例 B 跳过

🔵 部署与模板

🚀
deployments
部署记录。项目发布到预览/生产环境的记录，包含 URL、提供商（Vercel 等）、部署状态和次数。
例：项目 p1 部署到 Vercel，URL 为 https://preview-abc.vercel.app
📦
templates
可复用模板。从已有项目保存为模板，包含文件列表（JSON）。独立表，不与其他表关联。
例：用户把"产品发布会 PPT"保存为模板，下次直接复用
