表分组说明

分组 表 说明
核心业务 projects, conversations, messages, agent_sessions 项目 → 会话 → 消息，构成聊天主链路
制品与 UI preview_comments, tabs, tabs_state 制品评审评论、工作区标签页状态
自动化 routines, routine_runs, routine_schedule_claims 定时任务定义、执行记录、调度锁
部署 deployments 项目的部署记录（URL、状态）
— templates 可复用模板（独立，无外键关联）
