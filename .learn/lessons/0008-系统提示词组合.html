第 8 课：系统提示词组合

上下文注入、技能 + 设计系统 — 理解 AI 应用的"灵魂" · 预计 25 分钟

什么是系统提示词（System Prompt）？

系统提示词是发给 AI 的第一段文字，定义 AI 的角色、能力和行为规范。它不是用户消息，而是"操作手册"。

对比 ChatGPT

类型例子谁来写
系统提示词"你是一个有帮助的助手，使用 Markdown 回答"应用开发者
用户消息"什么是 SSE？"用户
AI 回复"SSE 是 Server-Sent Events..."AI

Open Design 的特殊挑战

Open Design 的系统提示词不只是"你是助手"，还要：

  • 📋 定义代理的技能（如 deck-creator、image-gen）
  • 🎨 应用设计系统（如 Linear 风格）
  • 🎯 注入用户上下文（项目记忆、自定义指令）
  • 🛠️ 启用MCP 工具（文件系统、图片生成）
  • 📐 强制craft 规则（无障碍、动画、反 AI 味道）
  • 🗣️ 选择回复语言（中文/英文）

这就像给一个新人写"入职手册"——需要把所有相关背景一次性告诉它。

组合流程

用户项目（skill_id, design_system_id, custom_instructions） ↓ composeSystemPrompt() 组合器 ↓ ┌─────────────────────────────────────────────────────┐ │ 1. 基础身份 (You are an AI assistant...) │ │ 2. 行为规范 (Be concise, use Markdown...) │ │ 3. 技能定义 (Skill: deck-creator SKILL.md) │ │ 4. 设计系统 (Design system: Linear) │ │ 5. Craft 规则 (Craft: a11y-baseline, ...) │ │ 6. 工具清单 (Available tools: file, image) │ │ 7. 用户上下文 (Project memory, history) │ │ 8. 自定义指令 (User's custom instructions) │ │ 9. 输出格式要求 (Output format: HTML/Markdown) │ └─────────────────────────────────────────────────────┘ ↓ 完整的系统提示词（可能几千字） ↓ 发送给 AI 代理

真实代码：apps/daemon/src/prompts/system.ts

composeSystemPrompt 函数

function composeSystemPrompt(opts: {
  basePrompt: string;        // 基础提示
  skill: SkillDefinition;    // 技能定义
  designSystem: DesignSystem;// 设计系统
  craftRules: string[];      // 工艺规则
  customInstructions: string;// 用户自定义
  userLanguage: string;      // 用户语言
}): string {
  const parts: string[] = [];

  // 1. 基础部分
  parts.push(opts.basePrompt);

  // 2. 技能定义（SKILL.md 内容）
  parts.push(`## Skill: ${opts.skill.name}\n\n${opts.skill.instructions}`);

  // 3. 设计系统
  parts.push(`## Design System\n\n${opts.designSystem.toMarkdown()}`);

  // 4. Craft 规则
  if (opts.craftRules.length) {
    parts.push(`## Craft Rules\n\n${opts.craftRules.map(r => `- ${r}`).join('\n')}`);
  }

  // 5. 自定义指令（最高优先级，用户说了算）
  if (opts.customInstructions) {
    parts.push(`## Custom Instructions\n\n${opts.customInstructions}`);
  }

  // 6. 输出格式
  parts.push(`## Output Format\n\nRespond in HTML or Markdown as appropriate.`);

  return parts.join('\n\n---\n\n');
}

SKILL.md 文件结构

每个技能是一个 Markdown 文件，包含 YAML frontmatter：

---
name: deck-creator
mode: deck
scenarios: [design, marketing]
craft.requires:
  - a11y-baseline
  - typography-hierarchy
---

# Skill: deck-creator

You are a presentation designer. Create slide decks with these principles:

## Output Format
- Generate a single self-contained HTML file
- Use 16:9 aspect ratio (1280x720)
- Include navigation controls (← →)

## Structure
- Each slide is a `
` with class `slide`
- Use semantic HTML
- No external dependencies (no CDN, no fonts)
💡 关键洞察：craft.requires 是 Open Design 独有的——技能声明自己依赖哪些通用规则，系统自动加载。这样新增 craft 规则时不需要改每个技能。

DESIGN.md 文件结构

设计系统也是 Markdown，9 段式：

# Design System: Linear

## 1. Color Palette
- Primary: #5E6AD2 (Linear purple)
- Background: #FBFBFB / #08090A (light/dark)
- Text: #1F1F1F / #F7F8F8

## 2. Typography
- Headings: Inter, 600 weight
- Body: Inter, 400 weight
- Scale: 1.250 (Major Third)

## 3. Spacing
- Base unit: 4px
- Scale: 4, 8, 12, 16, 24, 32, 48, 64

## 4. Layout Grid
- 12-column grid
- Gutter: 24px
- Max content width: 1200px

## 5. Components
- Button: rounded 8px, height 36px
- Card: rounded 12px, border 1px

## 6. Motion
- Easing: cubic-bezier(0.23, 1, 0.32, 1)
- Duration: 200ms enter / 140ms exit

## 7. Voice
- Concise, technical, direct
- Avoid marketing speak

## 8. Brand Guidelines
- Logo: Linear wordmark + glyph
- Never use generic SaaS illustrations

## 9. Anti-Patterns
- ❌ Gradients on backgrounds
- ❌ Drop shadows on flat elements
- ❌ Emoji as UI icons

提示词压缩：Token 预算

系统提示词太大会挤占用户消息的空间。需要平衡：

组件典型大小必要性
基础身份200-500 tokens必需
技能定义500-2000 tokens必需
设计系统500-1500 tokens强烈推荐
Craft 规则100-500 tokens推荐
自定义指令用户决定可选
工具清单100-300 tokens必需

优化技巧

  • 设计系统支持 summary 模式（压缩为关键 token）
  • 技能可以有 minimal 模式（只保留核心指令）
  • 重复内容用变量引用，避免硬编码
